Medicines Screen Button Width Test

Original Button (Full Width)
This button uses w-full or col-span-2 which makes it 100% width on all screens.
Issue: On mobile screens, this button takes up the entire width of the card, which can look too wide and unbalanced.
New Button (50% Width)
This button uses w-1/2 with flex justify-center on the parent, making it 50% width and centered.
Fixed: Button is now 50% width and centered, which looks more balanced on mobile screens.
Implementation Details

Code Changes Made:

// Before:
<div className="grid grid-cols-2 gap-3 pt-4 border-t border-slate-100">
  <button className="col-span-2">View Details</button>
</div>

// After:
<div className="pt-4 border-t border-slate-100 flex justify-center">
  <button className="w-1/2">View Details</button>
</div>

What This Does:

  • Parent div: Changed from grid to flex with justify-center to center the button
  • Button: Changed from col-span-2 to w-1/2 for 50% width
  • Result: Button is now 50% width and centered on all screen sizes
File: src/pages/Medicines.tsx (MedicineCard component)
Testing Instructions
  1. Run the application: npm run dev
  2. Navigate to the Medicines page
  3. Resize your browser to mobile size (under 640px)
  4. Check that the "View" button is now 50% width and centered
  5. Compare with the original full-width button behavior

Note: The button will maintain 50% width on all screen sizes (mobile, tablet, desktop). If you need different widths for different screen sizes, we can use responsive classes like w-full sm:w-1/2 lg:w-1/3.
