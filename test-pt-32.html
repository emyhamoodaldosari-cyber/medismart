Testing pt-32 Padding Change

CSS Variable:

--spacing: 0.25rem (4px)

Original pt-32:

calc(var(--spacing) * 32) = 32 * 0.25rem = 8rem = 128px

This has original pt-32 padding (128px top padding)

Custom pt-32 (what we want):

calc(var(--spacing) * 5) = 5 * 0.25rem = 1.25rem = 20px

This has custom pt-32 padding (20px top padding)

Comparison:

Class Calculation Result Visual Size
.pt-32-original var(--spacing) * 32 128px Very large padding
.pt-32-custom var(--spacing) * 5 20px Moderate padding
